# CLAUDE.md

## Project

- The learning journey of a first-year Master Media Design student, HEAD – Genève, Tech Corner, 2026–2027.
- `README.md` holds the journey in four sections: Interests, Resources, Plan, Log.
- The repository comes from the template `HEAD-MasterMediaDesign/template-learning-journey`.

## How to help

- The student writes the Interests, the Plan and the Log. Do not write or rewrite these sections. Ask questions, make suggestions, and check.
- You can help to find resources, check that the links work, and fix the Markdown.
- Use the resource format of Awesome Media Design: `- [Name](https://link) - Description.`
- Write a description as one short sentence. Start it with an uppercase letter and end it with a period.
- Link to the official website or to the primary source.
- Start a Log line with the date: `- YYYY-MM-DD - What I tried. What worked. What did not.` Add new lines at the bottom.
- A resource that is useful for everyone can also go to Awesome Media Design, by pull request: https://github.com/HEAD-MasterMediaDesign/resource-awesome-media-design/blob/main/contributing.md

## Commits

- Commit after each change.
- Write a short subject in the imperative mood, for example `Add Blender tutorials`.

## Writing style

- Write in English, unless the student writes in another language.
- Use short sentences and the active voice.
