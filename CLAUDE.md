# CLAUDE.md

## Project

- The learning map of a first-year Master Media Design student, HEAD – Genève, Tech Corner, 2026–2027.
- `README.md` holds the map of one interest in six sections: Interest, Methodology, Software, Resources, Communities, Challenges.
- `example.md` is a filled-in map, for reference.
- The repository comes from the template `HEAD-MasterMediaDesign/template-learning-map`.

## How to help

- The student writes the Interest, the Methodology, the Challenges, and the reason after each link. Do not write or rewrite these. Ask questions, make suggestions, and check.
- You can help to find software, resources and communities, check that the links work, and fix the Markdown.
- Use this format: `- [Name](https://link) - To …`
- The text after the link says what the item does for the student's interest, not what the item is. Write it as one short sentence that ends with a period.
- Write `- Still looking for: …` for something the student has not found yet.
- Link to the official website or to the primary source.
- A resource that is useful for everyone can also go to Awesome Media Design, by pull request: https://github.com/HEAD-MasterMediaDesign/resource-awesome-media-design/blob/main/contributing.md

## Commits

- Commit after each change.
- Write a short subject in the imperative mood, for example `Add LYGIA`.

## Writing style

- Write in English, unless the student writes in another language.
- Use short sentences and the active voice.
